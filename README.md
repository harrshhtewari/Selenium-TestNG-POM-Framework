# Selenium TestNG POM Framework

## Overview

This project demonstrates UI Automation using Selenium WebDriver, Java, TestNG, Maven, and Page Object Model (POM).

## Technologies Used

- Java
- Selenium WebDriver
- TestNG
- Maven
- Page Object Model
- GitHub

## Features

✅ Automated UI Testing

✅ Page Object Model Design Pattern

✅ Reusable Framework Components

✅ TestNG Reporting

✅ Cross Browser Testing

## Test Scenarios

- Login Validation
- Form Submission
- Excel Read and Write
- Browser Launch and Close Validation
